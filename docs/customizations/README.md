# Customizations Ledger

This folder is the living ledger for **custom** theme work in this repo.

Principles:
- Prefer documenting changes as small entries in typed ledgers (sections/assets/snippets/etc).
- Keep entries concrete: what it is, where it lives, the DOM/API contract, and how to debug it.

Ledgers:
- `sections.md`
- `assets.md`
